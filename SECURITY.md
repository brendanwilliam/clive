# Security policy

## Supported versions

Clive is prerelease software. Security fixes are provided on the latest commit of `main` and, when practical, the newest prerelease only.

## Report a vulnerability

Do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/brendanwilliam/clive/security/advisories/new) or email `clive.maintainers@gmail.com`. Include affected versions, reproduction steps, impact, and any suggested mitigation. Avoid including live credentials, pairing QR codes, private keys, or terminal contents.

You should receive an acknowledgement within seven days. The maintainer will coordinate validation, remediation, disclosure, and credit with you. Please allow a reasonable remediation period before public disclosure.

For non-security bugs, use the public bug report form.
