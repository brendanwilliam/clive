# Governance

Clive currently uses a lightweight single-maintainer model. Brendan Keane (`@brendanwilliam`) is the project maintainer and final decision-maker for roadmap, releases, security response, and repository administration.

Decisions should be discussed in issues or pull requests and evaluated against the security model, user impact, maintainability, and project scope. The maintainer may delegate review or maintenance responsibilities as the contributor community grows. Governance changes will be documented here before taking effect.

Contributors may appeal a decision by opening an issue with new technical evidence. Security-sensitive disputes should be sent privately using [SECURITY.md](SECURITY.md).
